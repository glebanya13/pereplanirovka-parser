Xlsx файл – опись состоит из таких листов, которые должны быть заполнены:
7.1.Удовлетоврённые – в этом листе нужно группировать по ФИО судьям все дела, которое удовлетворил по номеру возрастания номера решения.
7.2.Отказные – в этом листе нужно группировать по ФИО судьям все дела, в которых судья отказал истцу по номеру возрастания номера решения.
7.3. Статистика по судьям и представ – показал в примере как нужно, сверху идут судьи по самым крупным количествам дел, как показано в  примере. Аналогичный блок по представителям истца сделать. 
7.4. Решения с более одной инстанции – показал цветовые выделения по каждому суду, соответственно нужно выводить только те строчки, где это дело рассматривалось, т.е. если дело рассматривалось в первой, во второй и в третей инстанции значит только эти три строки выводить,  в данный лист выводятся только те дела, у которых более одной инстанции было!
7.5.На проверку – тут выводятся по аналогии с листом «Удовлетворённые» все дела по которым еще нет текста решения (определения) по всем типам судов 
7.6. По номеру дела – тут выводятся все решения с группировкой по номеру дела в нарастающем порядке (по номеру)

7.8.1. Представитель истца ФИО - нужно указать его ФИО. Скорее всего эти сведения тоже могут быть обезличены.  Поэтому лучше брать из текста решений опубликованных на агрегаторе https://судебныерешения.рф
