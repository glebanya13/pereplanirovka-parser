# Парсер решений по делам о перепланировке (Нижний Новгород)

Проект по ТЗ «ТЗ на парсинг по конкретному типу дел перепланировка июль 2026».
Не связан с govorenok.ru — отдельный клиентский заказ.

## Важное ограничение по ПДн (см. обсуждение с исполнителем)

ТЗ (п.7.8.1, 7.8.4, п.11) требует для папок «Выигранные»/«Проигранные» брать
полные (не обезличенные) ФИО истца и представителя, специально выбирая тот
источник, где суд не смог скрыть эти данные при публикации (обычно это
агрегатор судебныерешения.рф, а не официальный sudrf.ru, который обязан
обезличивать по 262-ФЗ).

Договорённость: заказчик подтвердил, что делает это по ТЗ как есть — значит
код реализует поиск наименее обезличенного источника как отдельный,
явно выделенный шаг (см. `src/linking.py::pick_best_source_for_names`), а не
скрытую логику внутри общего пайплайна. Если возникнут сомнения в законности
использования — эту функцию легко отключить одним флагом.

## Демо vs реальный прогон

| Команда | Что это |
|---|---|
| `--demo` | **Не готовый продукт.** 2–3 выдуманных дела — только проверка, что xlsx/docx собираются в нужной структуре. Заказчику не отдавать. |
| `--scrape` | **Реальный парсинг** с судебныерешения.рф. После завершения — готовый результат в `output/`. |

## Структура

```
config/regions.yaml       — список судов региона (заполняется по мере обнаружения)
src/models.py              — модель данных: Decision, CaseChain
src/markers.py             — детекция маркеров (несущая стена, экспертные организации, тип иска)
src/linking.py             — связывание решений одного дела по инстанциям
src/scrapers/              — по одному модулю на источник
src/report/xlsx_builder.py — сборка 8 листов xlsx по разделу 7 ТЗ
src/report/archive_builder.py — сборка папок Выигранные/Проигранные/Несколько инстанций
src/main.py                 — оркестратор CLI
data/raw/                   — сырые данные скрапинга (кэш, по источникам)
output/xlsx/                — готовые xlsx-описи
output/decisions/           — архив текстов решений
```

## Статус (2026-07-03, обновлено)

Готов пайплайн xlsx + docx (проверен `--demo`). Реализован рабочий скрапер
**судебныерешения.рф** (`--scrape`). Каркасы остальных источников в
`src/scrapers/`. Проверка доступности: `python scripts/check_sources.py`.

```bash
# демо — только проверка структуры файлов (фейковые дела):
python3 -m src.main --demo

# реальный парсинг — готовый результат для заказчика (период 2020–2026 по умолчанию):
python3 -m src.main --scrape

# один район (1-я инстанция), 2–4-я инстанции подтягиваются автоматически:
python3 -m src.main --scrape --district "Автозаводский район"

# пересборка xlsx/docx из кэша data/raw/sudreshenia без повторного скрапинга:
python3 -m src.rebuild
```
