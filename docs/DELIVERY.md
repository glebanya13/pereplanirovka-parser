## Текст письма

Добрый день!

По ТЗ на парсинг дел о перепланировке (Нижний Новгород, 2024–2026) подготовлен рабочий инструмент и демонстрационный комплект.

**Что сделано:**

1. **Скрипт парсинга** — собирает решения по всем 8 районным судам Н. Новгорода, апелляции (областной суд), кассации (1kas), надзору (ВС РФ), формирует сквозные цепочки по инстанциям.

2. **Источники:**
   - `судебныерешения.рф` — основной, рабочий (полные ФИО, тексты решений)
   - `vsrf.ru` — каркас поиска подключён
   - `sudrf.ru` (районные, oblsud, 1kas) — каркас Playwright, нужен российский IP
   - `sudact.ru` — каркас Playwright
   - `bsr.sudrf.ru` — **недоступен** с текущего IP (timeout); нужна проверка с вашей стороны без VPN

3. **Выходные файлы (по ТЗ п.7 и п.11):**
   - xlsx-опись на каждый район (6 листов: Удовлетворенные, Отказанные, Статистика, Несколько инстанций, На проверку, По номеру дела)
   - общий xlsx «Все районы» + лист «Районы»
   - архив docx: папки Выигранные / Проигранные / Несколько инстанций
   - xlsx-опись лежит и в `output/xlsx/`, и внутри папки каждого района

4. **Отбор дел** — по маркерам перепланировки/переустройства/переоборудования (п.8.2), не плоский поиск.

5. **ФИО истца/представителя** — отдельный явный шаг выбора наименее обезличенного источника (п.7.8.1, п.11), отключается флагом `--no-full-names`.

**Что приложено к письму:**
- Демо-комплект (`output/`) — структура xlsx и docx на тестовых данных, сверена с эталоном
- Инструкция по запуску (`README.md`)
- Сверка с ТЗ (`docs/TZ_CHECKLIST.md`)

**Для получения полного комплекта по реальным данным** нужно запустить на машине с российским интернетом без VPN:

```bash
cd pereplanirovka-parser
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
python scripts/check_sources.py          # проверить доступность
python3 -m src.main --scrape             # все районы, все инстанции (~несколько часов)
```

Один район для проверки:
```bash
python3 -m src.main --scrape --district "Автозаводский район"
```

**Требуется от вас:**
1. Подтвердить доступность `bsr.sudrf.ru` без VPN (сейчас timeout)
2. Подтвердить, что демо-структура xlsx совпадает с эталоном «ТЗ форма для парсинга. перепланировка.xlsx»
3. После полного прогона — выборочная сверка 5–10 дел

**Не входит в текущую поставку (следующий этап):**
- Полная интеграция sudrf.ru / sudact.ru / bsr.sudrf.ru как параллельных источников для перекрёстной сверки ссылок
- Гарантия 100% полноты (п.9 ТЗ) — требует полного прогона + ручной сверки; сайты очень медленные (п.12)

Готов обсудить полный прогон и доработку по остальным источникам.
